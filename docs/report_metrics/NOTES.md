# Report metrics: notes

Models: the YOLO11s detector is fully trained (100 epochs) but on FLIR street scenes, not on POP; the EDSR checkpoint is preliminary (an older 10-epoch run on non-POP data); the colorizer is preliminary (3 epochs on 75 train / 25 val LLVIP pairs, CPU, 12.96 min). Subsets (seed 0): SR on 30 POP test images, colorization on 50 synthetic test pairs (150 degraded images), detection on 100 POP test images for the thermal input and on 13 images for the colorized input (the same images as the runtime test), runtime on 10 images after 3 warm-up runs, on CPU (x86_64, 4 threads). Surprising results: EDSR is worse than bicubic (34.24 vs 47.89 dB PSNR), and the detector finds few POP people (recall 0.029, mAP@0.5 0.026 on thermal; 0.000 / 0.000 on colorized vs 0.000 / 0.000 on thermal for the same images). Interpretation: these numbers measure untrained-on-target models, so they show the pipeline runs end to end but not what it can reach once EDSR, the colorizer and YOLO are trained on POP and the paired set on a GPU.
